## What Is the COH150 Cohesity Multicloud Exam?

The COH150 exam is the certification exam for the Cohesity Certified Protection Associate – Multicloud credential. It evaluates candidates' understanding of Cohesity Data Cloud administration and the technologies used to protect and manage data across on-premises and public cloud environments.

The exam focuses on practical knowledge of:
- Cohesity Data Cloud architecture and cloud deployment models
- CloudArchive for long-term retention and recovery
- CloudTier for cloud-based storage tiering
- CloudSpin for virtual machine migration and cloning
- Cloud-native backup operations
- Multicloud deployment requirements and integration

These skills help professionals understand how to extend data protection beyond traditional on-premises infrastructure and take advantage of cloud resources.

Deployment Considerations is the largest domain at 25%, followed by Cohesity Cloud Concepts at 21.67% and Archiving with Cohesity at 20%. Together, these three areas represent approximately two-thirds of the exam, so they deserve particular attention during preparation. 

## 1. Cohesity Cloud Concepts — 21.67%

This domain covers the core concepts behind Cohesity cloud solutions and the different ways the platform can be deployed and used.

Candidates should understand:
- Supported Cohesity delivery models
- Available Cohesity cloud solutions
- Cloud solution use cases
- Native Cohesity cloud features
- Differences between archiving and tiering
- CloudSpin-based virtual machine cloning and migration
- Cloud-based disaster recovery
- CloudArchive use cases

The key is to understand which Cohesity capability best fits a particular business requirement, such as long-term retention, workload migration, or recovery in the cloud.

## 2. Archiving with Cohesity — 20%

This domain focuses on using Cohesity CloudArchive to store backup data in external cloud targets and support recovery requirements.

Candidates should understand:
- How archiving supports disaster recovery
- CloudArchive workflows
- Available external target options
- Recovery options for archived data
- CloudRetrieve disaster recovery workflows
- CloudArchive Direct configuration options

Preparation should emphasize the relationship between archive configuration, external storage, and the ability to retrieve protected data when recovery is required.

## 3. Tiering with Cohesity — 10%

This domain evaluates how Cohesity CloudTier uses cloud storage to support data tiering.

Candidates should understand:
- The benefits of cloud-based tiering
- CloudTier configuration options
- External target configuration
- CloudTier operational workflows
- Available tiering options

A useful distinction to remember is that archiving and tiering serve different data management purposes. Candidates should understand how each approach supports storage efficiency and business retention requirements.

## 4. Cloud-Native Backups with Cohesity — 15%

This domain covers running Cohesity natively in public cloud environments and protecting cloud workloads.

Candidates should understand:
- Configuring Cohesity for native operation in AWS, Microsoft Azure, or Google Cloud Platform (GCP)
- Networking differences between cloud-native deployments and on-premises clusters
- Supported cloud-native backup operations

Focus on understanding the infrastructure and networking considerations involved in protecting workloads directly within public cloud environments.

## 5. Cloud Migration with Cohesity — 8.33%

This domain focuses on CloudSpin capabilities for moving virtual machines between on-premises environments and public clouds.

Candidates should understand:
- CloudSpin migration use cases
- CloudSpin configuration
- Performing migration operations
- Using CloudSpin for development and test clones

The main preparation goal is to understand when CloudSpin is appropriate and how its workflows support migration and cloning requirements.

## 6. Deployment Considerations — 25%

This is the largest COH150 exam domain. It focuses on the requirements for deploying and operating Cohesity solutions in cloud environments.

Candidates should understand:
- Cloud storage types supported by CloudArchive
- Prerequisites for configuring CloudArchive with public cloud providers
- Requirements for running Cohesity natively in AWS, Azure, and GCP
- Additional capabilities available in hybrid on-premises and cloud deployments
- Cloud source registration requirements
- SaaS applications that Cohesity can protect

This section requires candidates to connect deployment prerequisites with the intended cloud architecture. Review networking, cloud storage, source registration, and the capabilities available when on-premises and cloud deployments work together.
